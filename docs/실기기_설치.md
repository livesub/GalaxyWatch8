# 갤럭시 워치8 클래식 실기기 설치 절차 (ADB 무선 디버깅)

## 1. 사전 준비
- 워치와 PC(개발 PC)를 **같은 Wi-Fi 네트워크**에 연결
- 워치에서 개발자 모드 활성화: 설정 > 워치 정보 > 소프트웨어 정보 > **빌드 번호 7회 연속 탭**
- 설정 > 개발자 옵션 진입 후: **ADB 디버깅** ON, **무선 디버깅** ON

## 2. PC-워치 페어링
1. 워치 무선 디버깅 화면에서 "페어링 코드로 새 기기 페어링" 선택 → IP:포트, 6자리 코드 표시됨
2. PC에서:
   ```
   adb pair <워치IP>:<페어링포트>
   ```
   코드 입력 요구 시 워치 화면의 6자리 코드 입력
3. 페어링 완료 후 워치 메인 무선 디버깅 화면에 표시된 연결용 IP:포트로 접속:
   ```
   adb connect <워치IP>:<연결포트>
   ```
   (페어링 포트와 연결 포트가 다름 — 워치 화면에 각각 별도 표시됨)
4. 확인:
   ```
   adb devices
   ```
   워치 시리얼이 `device` 상태로 뜨면 연결 성공

## 3. 빌드 & 설치
```
.\gradlew.bat :watchface:assembleDebug
adb install -r watchface\build\outputs\apk\debug\watchface-debug.apk
```
- 지금 단계는 디버그 서명으로 설치 — keystore(정식 서명)는 CLAUDE.md 8번대로 아직 필요 없음(추후 배포 단계에서 별도 생성)

## 4. 워치페이스 활성화
- 워치에서 직접: 홈 화면 길게 눌러 워치페이스 목록에서 "바람개비 워치8 클래식" 선택
- 또는 PC에서 강제 활성화(에뮬레이터 테스트와 동일 명령):
  ```
  adb shell am broadcast -a com.google.android.wearable.app.DEBUG_SURFACE --es operation set-watchface --es watchFaceId com.keingma.watch
  ```

## 5. 실기기에서만 확인 가능한 항목
- **날씨(WEATHER.*)**: 에뮬레이터는 위치 못 가져와 전부 미수신이었음 — 실기기는 실제 GPS로 온도/날씨아이콘/일몰·일출 정상 수신되는지 확인
- **심박수(HEART_RATE)**: 최초 활성화 시 BODY_SENSORS류 권한 요청 다이얼로그가 뜰 수 있음 — 허용해야 실제 값 표시됨
- **걸음수(STEP_COUNT)**: 삼성 헬스 연동 상태에 따라 값 반영 확인
- **콤플리케이션 6개**: 실제 앱 설치 후 SLOT_TOP_LEFT/TOP_RIGHT/MID_LEFT/MID_RIGHT에 원하는 앱 재지정해서 아이콘 렌더 확인
- **AOD**: 실기기에서 화면 꺼짐 전환 시 시:분만 남는지, 픽셀 사용률(3-3, 15% 이하 권장) 육안 확인

## 6. 문제 발생 시
- `adb connect` 실패: 워치·PC가 같은 서브넷인지, 방화벽이 ADB 포트를 막는지 확인
- 연결 끊김: 워치 화면 꺼짐/절전으로 무선 디버깅이 비활성화될 수 있음 — 재연결 필요

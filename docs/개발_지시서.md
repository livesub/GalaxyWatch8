# 갤럭시 워치8 워치페이스 개발 지시서 (단계별)

사용법: 매 단계 끝나면 새 세션이든 이어서든 다음 단계 프롬프트를 그대로 복붙. 각 단계 끝에 "PROGRESS.md 체크박스 갱신해줘"까지 포함돼 있음. 한도 걸리면 리셋 후 같은 단계 프롬프트 다시 붙여넣으면 됨(어차피 CLAUDE.md/PROGRESS.md가 상태를 들고 있음).

**공통 규칙(3단계부터 화면 배치하는 모든 단계에 적용)**: `src/main/design/orgi.png`는 1024x1024 목업이라 좌표 그대로 쓰면 안 됨 — 요소 위치/폰트크기를 비율(%)로 환산해서 실제 캔버스(438x438)에 맞게 배치할 것.

---

## 1단계: 프로젝트 골격
```
CLAUDE.md 기준으로 Android/WFF 프로젝트 골격 만들어줘.
build.gradle, settings.gradle, AndroidManifest.xml, 폴더구조(watchface/src/main/res/drawable, watchface/src/main/res/raw, src/main/design)까지.
끝나면 PROGRESS.md 1번 체크하고 상태 기록해줘.
```

## 2단계: 리소스 변환
```
CLAUDE.md 3-4 규정대로 날씨 아이콘 32종(PNG 480x480)을 WebP로 변환하고 실제 표시 크기로 리사이즈하는 스크립트 만들고 실행해줘. 결과물은 watchface/src/main/res/drawable에(root의 src/main/res/drawable 아님).
끝나면 PROGRESS.md 8번 체크해줘.
```

## 3단계: 메인 시계 + 날짜 + 요일색
```
watchface.xml에 메인 시계(12시간제, 오전/오후), 날짜, 요일(7색+다크아웃라인) 구현해줘. CLAUDE.md 5번, 6-1번 참조.
orgi.png(1024x1024 목업)는 좌표 그대로 쓰지 말고, 위치/폰트크기를 비율로 환산해서 438x438 캔버스에 맞게 배치할 것.
끝나면 PROGRESS.md 2번 체크해줘.
```

## 4단계: 온도 + 날씨 아이콘 조건분기
```
WEATHER.TEMPERATURE로 온도 표시하고, docs/weather_icons.md 매핑표대로 day/night + CONDITION별 날씨 아이콘 조건분기 구현해줘.
끝나면 PROGRESS.md 3번 체크해줘.
```

## 5단계: 배경 연결
```
배경을 주간/야간 + 날씨조건별로 자동 전환되게 연결해줘. 원형 크롭 필수(CLAUDE.md 3-4). 배경 이미지 파일이 아직 없으면 어떤 파일이 필요한지 목록만 먼저 알려줘.
끝나면 PROGRESS.md 6번 체크해줘.
```

## 6단계: 콤플리케이션 슬롯 1~2 (앱 바로가기)
```

끝나면 진행상황만 알려줘(PROGRESS.md 4번은 6개 슬롯 다 끝나면 체크).

## 21-2단계: 초/날씨아이콘 크기·정렬 수정 (실측 기반)

```

1. 초(seconds) 텍스트: 스펙(CLAUDE.md 5-2, x311/y274/w49/h50, font-size 44px급)의 약 75% 크기로 작게 렌더됨(실측 잉크높이 30px, 데모 40px). 또한 메인시계 하단(baseline, y332) 기준 정렬이 안 되고 위로 떠 있음(실측 y283~313, 데모는 y277~317로 더 아래). 메인시계(시:분)와 같은 방식으로 폰트 적용됐는지 확인하고, align-self:flex-end 상당(하단 정렬)로 고쳐줘.
2. 날씨 아이콘: 스펙 박스(CLAUDE.md 5-2, y121~226, h105) 대비 실측 세로 114px로 박스를 벗어남(박스 상단보다 13px 위로 튀어나옴: 실측 y108~222). Image 리소스 크기를 박스(h105) 안에 비율 유지한 채 들어가도록 축소하고 박스 내 수직 중앙정렬 해줘.

끝나면 다시 빌드/에뮬레이터 캡처해서 보여주고 PROGRESS.md에 기록해줘.
```

## 21-3단계: 날짜행 중앙정렬 + 초 재확인 (실측 기반, 21-2 미반영 확인됨)

```
아래 2건, 새 에뮬레이터 캡처를 데모(demo_final.png)와 겹쳐 재측정한 결과 확정.

1. 날짜행(2026.MM.DD+요일) 가로 위치 오류: 왼쪽으로 심하게 치우쳐 SLOT_MID_LEFT 원형 콤플리케이션(스펙 x70~122)과 겹침(실측 텍스트 시작 x≈45, 원 안쪽까지 침범). 반대로 오른쪽(SLOT_MID_RIGHT, x316~368)과는 간격이 76px로 과도하게 벌어져 있음(데모는 좌우 각각 약 23~38px로 대칭). 캔버스 전체(x=0, width=438) 기준 완전 중앙정렬로 좌우 대칭 맞추고, 어떤 경우에도 좌우 원형 슬롯과 겹치지 않게 해줘.
2. 초(seconds) 크기/정렬: 이전 21-2단계 1번 요청(스펙 x311/y274/w49/h50, 메인시계 하단 정렬)이 실제로 반영 안 된 것으로 재측정됨(여전히 잉크높이 약 30px, 스펙/데모 40px). watchface.xml에 실제로 값이 바뀌었는지 먼저 확인하고 다시 적용해줘.

## 22단계 (완성 후): 미리보기 이미지(Preview) 등록
```
워치페이스 선택화면에 뜨는 미리보기 이미지 등록해줘. "런처 아이콘"이 아니라 WFF의 Preview 리소스임 — 별도 로고/썸네일 디자인이 아니라 완성된 실제 워치페이스 화면 그대로 캡처한 이미지를 쓰면 됨.
1. 에뮬레이터에서 완성된 워치페이스 스크린샷(438x438, 배경 원형 크롭 상태 그대로) 찍어서 watchface/src/main/res/drawable/preview.png로 저장
2. watchface/src/main/res/xml/watch_face_info.xml에 <Preview value="@drawable/preview" /> 등록(파일 없으면 새로 생성, WatchFaceInfo 루트 엘리먼트)
3. AndroidManifest.xml에 android:hasCode="false" 속성 있는지 확인(WFF는 코드 없이 리소스만 포함하는 게 정상)
끝나면 에뮬레이터에서 워치페이스 목록 화면 열어서 미리보기 잘 뜨는지 확인하고 PROGRESS.md에 기록해줘.
```

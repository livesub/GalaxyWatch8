# 갤럭시 워치8 워치페이스 개발 지시서 (최종본 기준 — 처음부터 빌드용)

이 문서는 지금까지 수십 라운드 수정/검수를 거쳐 확정된 최종 스펙(CLAUDE.md)을 기준으로, **새 프로젝트/새 세션에서 처음부터 시작해도 지금과 동일한 결과물**이 나오도록 정리한 빌드 가이드입니다. (과거의 시행착오 이력은 git 커밋 로그에 남아있고, 이 문서에는 최종 확정 사항만 담습니다.)

사용법: 아래 단계를 순서대로 CLI에 그대로 복붙. 한도 걸리면 리셋 후 같은 단계 프롬프트 다시 붙여넣으면 됨(CLAUDE.md/PROGRESS.md가 상태를 들고 있음).

**필요 리소스**: 시작 전에 CLAUDE.md 4-1번(날씨아이콘 32종, 우산아이콘, 배경 2종, 폰트 2종)을 미리 준비해둘 것. 없으면 CLI가 목록만 알려주고 대기함.


## 2단계: 리소스 준비 (이미지+폰트)
```
아래 순서로 리소스 준비해줘. 첨부 원본 파일들은 [경로 알려주면] 그 경로에서 가져가고, 없는 게 있으면 목록만 먼저 알려주고 멈춰.

1. 날씨 아이콘 32종(원본 480x480 PNG) → docs/weather_icons.md 매핑표 그대로 파일명 유지, WebP 변환 + 실제 표시크기(CLAUDE.md 5-2 "날씨 아이콘" 행, height=105 기준 비율)로 리사이즈. 결과물은 watchface/src/main/res/drawable/
2. 우산 아이콘(rain_umbrella, 원본 260x236) → 위와 동일 파이프라인으로 WebP 변환, watchface/src/main/res/drawable/rain_umbrella.webp
2-1. 하단 알약 아이콘 3종(icon_battery.png, icon_heart.png, icon_steps.png) → watchface/src/main/res/drawable/에 배치(별도 이미지 파일, 코드로 그리지 않음)
3. 배경 이미지 day/night 각 1장 → 원형 크롭 확인 후 watchface/src/main/res/drawable/bg_day.webp, bg_night.webp
4. 폰트 2종(notosanskr_bold.ttf, notosanskr_regular.ttf) → CLAUDE.md 4-1-4번의 76자 세트로 처음부터 서브셋(fonttools/pyftsubset)해서 watchface/src/main/res/font/에 배치(전체 글리프 버전은 만들 필요 없음, 처음부터 서브셋본만 사용)

끝나면 PROGRESS.md 8번 체크해줘.
```

## 3단계: 전체 레이아웃 한 번에 구현 (CLAUDE.md 5번/5-2 기준)
```
watchface.xml에 CLAUDE.md 5번(레이아웃 원칙)과 5-2(정확한 좌표 스펙표)를 그대로 구현해줘. 표에 있는 x/y/width/height/정렬/색상 값을 그대로 사용(비율 환산 불필요, 438x438 캔버스 기준 그대로).

포함 요소 전부 한 번에:
- 알림 점 + 알림 개수 (1번, 알림 있을 때만 표시)
- 최고/최저 기온 (1-1번, WEATHER.DAYS.0.TEMPERATURE_LOW/HIGH 확정 사용, 하드코딩 금지, 화씨→섭씨 변환 분기 포함)
- 강수확률 라벨+아이콘+값 (1-2번, WEATHER.CHANCE_OF_PRECIPITATION)
- 일출 라벨/시각, 온도, 일몰 라벨/시각 (2~4번)
- 날씨 캐릭터 아이콘(day/night 32종, WEATHER.CONDITION 조건분기, docs/weather_icons.md 매핑표 그대로) + 날씨 코멘트(온도 아래 2행)
- 날짜(x120,y227,w160,align=END) + 요일 7개(x285,y227,w40,align=START, 요일별 7색+다크아웃라인)
- 메인 시계(시:분, 12시간제+오전오후 세로표기) + 초(x311,y270,w70,h70)
- 하단 알약 3개(워치배터리/걸음수/심박수, 96x44 동일크기, 배터리·심박수 값 가운데정렬, 걸음수 값 오른쪽정렬 우측여백 14px 확정 — 24단계, 0~999999 전부 아이콘/테두리 간섭 없음 검증완료)
- 최하단 워치이름 "바람개비 워치8 클래식"(직선 텍스트, 피치톤)
- 배경(day/night 자동전환, 원형크롭)

색상/폰트는 CLAUDE.md 6-1~6-3 그대로. 폰트는 2단계에서 만든 서브셋 폰트를 `<Font family="notosanskr">`로 임베딩.

끝나면 에뮬레이터로 확인하고 PROGRESS.md에 기록해줘.
```

## 7단계: watch_face_info.xml 설정 (편집 가능 + 미리보기)
```
아래 2가지 한 번에 처리(둘 다 실기기/에뮬레이터에서 반드시 필요한 필수 설정, 과거 프로젝트에서 이걸 빠뜨려서 편집화면 진입 자체가 막히고 크래시났던 이력 있음):

1. watch_face_info.xml에 <Editable value="true" /> 명시(기본값 false라 이거 빠지면 즐겨찾기 목록에 "편집" 버튼 자체가 안 뜸)
2. 에뮬레이터에서 완성된 워치페이스 실제 화면 스크린샷(438x438, 원형 크롭 그대로) 찍어서 watchface/src/main/res/drawable/preview.png로 저장(래스터 PNG, VectorDrawable 절대 아님 — vector로 하면 SysUI에서 ClassCastException 크래시남). watch_face_info.xml에 <Preview value="@drawable/preview" /> 등록, AndroidManifest.xml의 icon/preview/preview_circular 메타데이터도 전부 이 preview.png(또는 WebP 변환본)로 통일.
3. AndroidManifest.xml에 android:hasCode="false" 속성 있는지 확인(WFF는 코드 없이 리소스만 포함하는 게 정상)

끝나면 즐겨찾기 목록 "편집" 버튼 뜨는지, 편집화면 진입 시 크래시 없는지, 4개 슬롯 앱 선택 가능한지 캡처로 확인하고 PROGRESS.md에 기록해줘.
```

## 8단계: 소스 최적화 (발열/배터리/로딩속도)
```
화면 결과물은 픽셀 단위로 완전히 동일해야 함(조금이라도 바뀌면 적용 금지, "적용 안 함: 이유"로 보고). 오류/크래시 최대한 내지 말 것.

1. 콤플리케이션 4개 슬롯 노드를 XML 최하단에 배치(AOD 메모리 계산 제외 효과) — 단 다른 요소와 바운딩박스 겹쳐서 렌더 순서 바뀌면 하지 말고 보고만
2. renderMode/blendMode/tintColor 사용 최소화(꼭 필요한 곳만, 예: 콤플리케이션 아이콘 흰색 틴트)
3. 초(seconds)처럼 매초 갱신되는 요소는 독립 Part/Group으로 분리해서 전체화면 재렌더 안 되게 구조화
4. WFF 공식 최적화 툴(google/watchface, tools/wff-optimizer) 적용 시도 — 이미지 파일 자체를 크롭/리스케일하는 기능은 픽셀 변화 위험 있으니 적용 전 반드시 확인 후 판단

끝나면 15단계 Validator로 메모리 측정하고(목표: Active 100MB 이하, AOD 10MB 이하 — 이미 검증된 최종본 기준 Active 약 3.2MB/AOD 약 13KB 수준 나와야 정상) PROGRESS.md에 기록해줘.
```

## 참고: 알려진 주의사항 (재발 방지용)
- WFF v5 시도 시 설치 자체 거부됨(FavoriteOperationException) — v2 고정
- watch_face_info.xml `Editable` 기본값이 `false` — 명시적으로 `true` 안 하면 편집화면 진입 불가
- Preview 리소스는 반드시 래스터(PNG/WebP), VectorDrawable 쓰면 SysUI 크래시
- `TextCircular`(곡선 텍스트)는 Wear OS 4+ 전용이라 v2에서 사용 불가 — 워치이름은 직선 텍스트로 확정
- 알약(하단 3개)은 stadium(rounded-rect, radius=height/2) 모양이라 상하단 근처에서 안쪽으로 휘어 들어감 — 픽셀 단위 목업/패치 작업 시 곡률 고려 필수(정확한 잉크 경계값으로만 패치, 박스 전체 기준 금지)
- 오전/오후·초 색상은 배경(보라~핑크 톤)과 겹치지 않는 코럴톤(#FFB27A)으로 확정 — 하늘색/주황 조합은 폐기된 안
- isAutoSize/verticalAlign/minSize 속성은 v2 XSD 검증에서 "미지원" 경고 뜨지만 실제 렌더는 정상 동작 확인됨(CLAUDE.md 1번) — 경고 보고 임의로 제거하지 말 것
- `TimeText`는 `Outline` 자식을 지원 안 함 — 메인 시계 다크 아웃라인은 동일 텍스트를 8방향 1~2px 오프셋 검정 복제 후 흰색 원본을 덮어그리는 방식으로 구현(CLAUDE.md 6-1 참조), `<Outline>` 자식으로 시도하면 안 됨
- 강수확률 값 필드는 `WEATHER.DAYS.0.CHANCE_OF_PRECIPITATION`(배열형) — 비배열형 `WEATHER.CHANCE_OF_PRECIPITATION` 아님
- 알약 아이콘(배터리/걸음수/심박수)은 코드로 그리는 벡터가 아니라 별도 PNG 파일(icon_battery.png 등) 참조 — 리소스 목록(4-1)에서 빠뜨리기 쉬우니 주의
